================================================================
     校园售货机销售提升分析 · 使用说明（大白话版）
================================================================

这份说明教你把一个叫「技能」的小工具装进 WorkBuddy。
装好以后，每周或每月把售货机的销售数据丢给它，
它自动出报告，并直接告诉你「哪里卖得不够好、该怎么改」。

不需要会编程，照着下面的步骤点就行，全程大约 5 分钟。

压缩包从哪来（两种都行）：
  1. 发你这份说明的人，应该同时发给你一个
     campus-vending-analysis.zip 文件。
  2. 或者打开这个网址，在页面最下面的 Assets 里下载
     那个 campus-vending-analysis.zip：

     https://github.com/09084887064r-oss/campus-vending-analysis/releases/tag/v1

----------------------------------------------------------------
第 0 步：先确认电脑里有 Python（只需做一次）
----------------------------------------------------------------

这个技能是用 Python 写的，所以电脑里得有一个 Python。

怎么查：
  1. 按住键盘上的 Win 键，再按 R 键，会弹出一个小窗口。
  2. 输入 cmd，按回车，会出现一个黑窗口。
  3. 在黑窗口里打下面这一行，按回车：

       python --version

看到类似 Python 3.12.4 这样的字，就说明有，直接看第 1 步。

如果显示「不是内部或外部命令」，说明没装：
  去 https://www.python.org/downloads/ 下载安装。
  装的时候务必把最下面的「Add python.exe to PATH」勾上，
  否则装完还是找不到。装完再回来重查一次。

----------------------------------------------------------------
第 1 步：把技能装进 WorkBuddy（两种办法，选一种）
----------------------------------------------------------------

办法一：上传压缩包（推荐，最快）
  1. 打开 WorkBuddy。
  2. 看左边那一竖排图标，找到「专家·技能·连接器」，点开。
  3. 点上面的「技能」标签。
  4. 点右上角「添加技能」，再点「上传技能」。
  5. 选中 campus-vending-analysis.zip，点打开（不用解压）。
  6. 等几秒，出现「安装成功」。

装成功的三个标志：
  - 有「安装成功」的提示
  - 列表里多了一个「校园售货机销售提升分析」
  - 它右边的小开关是打开的

如果上传时提示「包结构不正确」，直接用办法二。

办法二：手动复制（办法一报错时用）
  1. 右键 campus-vending-analysis.zip，选「全部解压」。
  2. 进解压出来的文件夹，里面应该直接有一个
     campus-vending-analysis 文件夹，
     点进去能看到 SKILL.md、scripts、assets、references。
  3. 在窗口最上面的地址栏输入下面这行，按回车：

       %USERPROFILE%\.workbuddy\skills\

  4. 把第 2 步那个文件夹整个拖进去。
     拖完的路径必须是：

       ...\skills\campus-vending-analysis\SKILL.md

     如果变成 ...\campus-vending-analysis\campus-vending-analysis\
     这种多套一层的样子，它就不认，要删掉重拖一次。
  5. 完全退出 WorkBuddy：右下角托盘图标右键，选「退出」。
     注意不是点窗口右上角的叉，那个只是关窗口。
  6. 重新打开 WorkBuddy，回到「技能」页面，
     把它右边的小开关拨开。

----------------------------------------------------------------
第 2 步：准备数据（每次分析都要）
----------------------------------------------------------------

最少要有 1 份销售明细。另外三份做对应分析时才需要。

  1. 销售明细（必须有）
     格式：Excel、CSV、JSON、TSV 都行
     必须有这几列：交易时间、机器编号、商品名称、
                   销售数量、销售金额
     列名不用一字不差，对不上它会问你「这列是不是交易时间」。
     如果还有「用户标识」「订单标识」，算出来更准。

  2. 商品分类表（想看品类分析就要）
     必须有：商品名称、品类

  3. 楼栋人数表（想看用户分析就要）
     必须有：楼栋、性别、老生人数、新生人数

  4. 机器和楼栋的对照表（想看哪栋楼卖得差就要）
     必须有：机器编号、楼栋

少哪一份它都会先停下来问你，不会自己瞎猜。
所以第一次用很可能出现「它先反问你几个问题」，
这是正常的，照着你的真实情况回答就行。

----------------------------------------------------------------
第 3 步：跑一次
----------------------------------------------------------------

  1. 在 WorkBuddy 里新开一个对话。
     （旧对话不会加载新装的技能，这条最容易忘）
  2. 把销售明细文件拖进输入框。
  3. 打一句话：帮我分析这份售货机数据
     想要周报就说「按周」，想要月报就说「按月」。
  4. 它可能依次问你：
       - 这列是不是交易时间？（列名对不上时）
       - 商品分类表在哪？
       - 楼栋人数表在哪？
       - 结果存到哪个文件夹？
  5. 回答完，它开始算，最后给你三份文件加一份清单。

----------------------------------------------------------------
第 4 步：结果存在哪
----------------------------------------------------------------

第一次它会问你「历史报告放在哪个目录」，
默认是 C:\Users\你的用户名\Documents\售货机数据归档。
定下来以后别再改，中途换目录，下一期就没法和上期比了。

里面的结构是这样：

  售货机数据归档\
      raw\2026-W45\        原始数据副本（不动你的源文件）
      processed\2026-W45\  清洗后的数据（下期算环比靠它）
      reports\2026-W45\    三份报告就放在这里

  2026-W45 表示「2026 年第 45 周」。
  月报的写法是 2026-11，表示 2026 年 11 月。

同一周重复跑，它会先问你「这周已有结果，要不要覆盖」。
你同意后，旧文件会被改名成 .bak 保留下来，不会真的丢。

----------------------------------------------------------------
第 5 步：报告怎么看
----------------------------------------------------------------

每次给三份文件，名字里都带周期：

  1. 校园售货机_销售提升分析_2026-W45.xlsx
     里面有十几个工作表。不是搞数据的只看两张就够：
       - 13_销售提升点清单  最重要，直接告诉你该干什么
       - 14_结论与建议      三句话总结、行动建议、风险提醒

  2. ..._交互报告.html
     双击用浏览器打开，能点、能筛选，适合给领导看。

  3. ...docx
     用 Word 直接打开就能改字，适合打印或者转发。

「销售提升点清单」每一行说的是：
  问题是什么 → 从哪个数字看出来 → 影响谁
  （哪台机器、哪个时段、哪个品类、哪栋楼）→
  建议怎么动 → 谁负责 → 预计能提升多少 →
  优先级 → 下期怎么验证有没有效果

----------------------------------------------------------------
第 6 步：看不懂的词，查这里
----------------------------------------------------------------

  技能          一套能让 WorkBuddy 干专门活的说明书加程序。
  数据根目录    存历史报告的那个文件夹，见第 4 步。
  周期键        2026-W45 是 2026 年第 45 周，2026-11 是 11 月。
  环比          这一期和上一期比，涨了还是跌了。
  价格带        把商品按单价分档，比如 0-3 元、3-5 元、
                5-8 元、8 元以上，看哪个价位卖得好。
                注意 3.00 元算在 3-5 元这一档。
  件单价        销售额除以卖出的件数，平均一件多少钱。
  客单价        销售额除以订单数，一个人来一次花多少钱。
  连带率        平均一单买了几件。
  渗透率        这一栋楼住的人里，有多大比例买过东西。
  人均消费      这一栋楼的销售额除以这栋楼住的人数。
  N/A           没有这项数据，算不出来。
                它不是 0，也不是猜的，直接不显示数值。

----------------------------------------------------------------
第 7 步：出问题怎么办
----------------------------------------------------------------

情况一：技能列表里找不到它
  九成是文件夹套了两层。打开这个路径看看：

    %USERPROFILE%\.workbuddy\skills\campus-vending-analysis\

  里面要能直接看到 SKILL.md。
  看不到就说明套层了，整个删掉，按办法二重新拖一次。

情况二：装好了但它不干活
  1. 检查「技能」页面里它的小开关是不是关着。
  2. 用右下角托盘图标彻底退出 WorkBuddy，再重新打开。
  3. 一定新开一个对话，旧对话不会加载新技能。

情况三：它说缺少依赖，还给了一行 pip install 命令
  这是正常提示，不是坏了。照它给的做：
  把那一行命令原样交给 WorkBuddy 执行，
  或者自己粘进第 0 步那个黑窗口里按回车。
  装完把刚才的命令重跑一遍就行，不用重新装技能。

情况四：只出了 Excel 和网页，没有 Word
  电脑缺 Word 报告要用的两个库，不影响结论，
  Excel 和网页里的内容是一样的。想补上就执行：

    python -m pip install python-docx matplotlib

情况五：报告里「上期」那一列是 N/A
  说明还没有上一期的数据，第二次开始跑就有了。
  N/A 不是错误，也不是 0。

情况六：它问了一堆问题，太啰嗦
  这些问题决定算得对不对（哪列是时间、哪列是数量、
  哪列是楼栋）。第一次配好之后，后面会沿用。

想彻底确认装好了，可以让 WorkBuddy 执行这一行：

  python "%USERPROFILE%\.workbuddy\skills\campus-vending-analysis\scripts\run.py" selftest

看到 "passed": 85, "failed": 0 就说明一切正常。

----------------------------------------------------------------
第 8 步：更新与卸载
----------------------------------------------------------------

  更新：先卸载，再按第 1 步装新的压缩包。
        新版压缩包在这里下载（认准编号最大的一版）：

        https://github.com/09084887064r-oss/campus-vending-analysis/releases

  卸载：「技能」页面把它的小开关关掉，然后到

        %USERPROFILE%\.workbuddy\skills\

        把 campus-vending-analysis 这个文件夹删掉。
        删技能不会删你的历史数据，
        数据都在「售货机数据归档」那个文件夹里。

----------------------------------------------------------------
附：压缩包里有什么
----------------------------------------------------------------

  INSTALL.md                安装说明（排版更好看的一版）
  使用说明.txt              就是这份，大白话版
  campus-vending-analysis\  技能本体，整个放进 skills 目录
       SKILL.md             技能说明书，WorkBuddy 靠它认识这个技能
       scripts\             真正的计算程序
       assets\              报告模板（Excel 样式、网页模板）
       references\          口径规则、校验规则、诊断手册
       data\                放历史归档的地方
