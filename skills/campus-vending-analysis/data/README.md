# data/ 目录说明

这里只放**归档结构的示例**，不放真实数据。

技能运行时的归档写在用户指定的数据根目录（默认 `文档\售货机数据归档`），不会写进技能目录 ——
因为技能升级会覆盖整个技能文件夹，把数据放里面等于埋在安装包里。

归档结构：

```
<数据根目录>/
├── .archive.json                 根目录自我描述（schema / 创建时间 / 布局）
├── manifest.jsonl                一期一行的运行台账
├── raw/<周期键>/                 原始文件副本
├── processed/<周期键>/           facts.csv + meta.json（口径指纹、计数、hash）
└── reports/<周期键>/             xlsx / html / docx / uplift_points.csv
```

周期键：周报 `2026-W45`（ISO 周），月报 `2026-11`（自然月）。两套键空间互不覆盖。
同一期重复运行：先以退出码 7 停下等你确认，确认后旧文件另存为 `.bak` 再覆盖。
