# 数据契约（输入字段与缺失降级）

## 三张表

| 表 | 必需 | 字段 | 别名（自动识别） |
|---|---|---|---|
| 销售明细 | 是 | 交易时间 | 交易时间/时间/销售时间/下单时间/order_time/sale_time |
| | | 机器编号 | 机器编号/机器/设备编号/售货机编号/machine |
| | | 商品名称 | 商品名称/商品/品名/商品名/products |
| | | 销售数量 | 销售数量/数量/件数/qty/quantity |
| | | 销售金额 | 销售金额/金额/销售额/应收金额/amount |
| | | 用户标识 | 用户标识/用户ID/学号/会员号/user/user_id |
| | 可选 | 订单标识 | 订单标识/订单号/交易号/order_id/order_no |
| 商品分类表 | 是 | 商品名称 → 品类 | 品类/二级分类/分类/category |
| 寝室楼栋人数表 | 是 | 楼栋 → 新老生人数 | 楼栋/楼栋组/宿舍楼；老生/新生/住宿人数（可选 性别） |

## 缺失降级（不估、不猜）

| 情况 | 行为 |
|---|---|
| 缺分类表 | **阻断**（preflight 退出码 3），不产出品类模块 |
| 缺人数表 | **阻断**，不产出渗透率/人均消费，用户模块只给消费侧 |
| 缺订单标识 | 订单数/连带率/客单价 全部 N/A，其余照常 |
| 缺用户标识 | 消费人数 N/A，用户模块只给楼栋金额 |
| 分类表未覆盖某商品 | 归入「未分类」单列，并在清洗日志登记金额 |
| 时间无法解析 | 排除并计入对账瀑布，不留空行 |
| 人数表未覆盖某楼栋 | 该楼栋渗透率 N/A（不是 0） |
| 负数/退款 | 默认排除出分析口径并单列（可配置计入） |

## 单品判定（写死，执行期不得改）

1. 不同规格算两个单品（`可乐 330ml` ≠ `可乐 500ml`）；
2. 同品不同名合并（`可口可乐` = `可乐`，取词表）；
3. 品牌不同不合并（`可口可乐` ≠ `百事可乐`）；
4. 规格缺失标「未标注规格」，不算错。
