# 校验规则与三态

| 状态 | 含义 | 后果 |
|---|---|---|
| PASS | 数值吻合（金额 ±0.01，占比 ±0.1pp） | 继续 |
| WARN | 差额已被解释（未分类、未归属、天数不等、口径变更） | 继续，但报告必须写明 |
| SKIP | 缺数据无法对账（无订单列、无上期） | 继续，报告写 N/A 及原因 |
| FAIL | 无法解释的差额 | **中止，不产出报表**（退出码 5） |

## 模块门禁（先过后进下一个模块）

- M1 核心：`CHK-M1-01` 本期销售额=口径合计；`CHK-M1-02` 订单数=去重订单标识（用行数即 FAIL）；`CHK-M1-03` 上期=基准合计；`CHK-M1-04` 天数不等必须用变化率。
- M2 时点：`CHK-M2-01` 24 桶；`02/03` 销量/销售额合计=总额；`04` 零时段保留。
- M3 价格带：`01` 合计=总额；`02` 占比合计 100%±0.1pp；`03` 件单价缺失单列；`04` 档位数=配置档位。档位区间固定「左闭右开」`[下限, 上限)`，所以 3.00 元属于 3–5 元档；第一档标签不得写「≤3 元」，要含 3.00 元请把上界设为 3.01。
- M4 品类：`01` 合计=总额；`02` 占比 100%；`03` 未分类单列。
- M5 机组：`01` 合计=总额；`02` 机组数>0；`03` 占比 100%。
- M6 用户：`01` 合计=总额；`02` 零消费楼栋保留；`03` 人数表覆盖检查；`04` 新老生人数必须可计算（人数表有该列却全为 N/A → FAIL，防止列名接错）。

## 环比专项

`CHK-CMP-*`：变化额=本期−上期（逐行）；上期为 0 时变化率必须 N/A；变化率与变化额同号。

## 全局交叉验证

`CHK-G-*`（六模块合计=本期总额）、`CHK-GP-*`（上期合计=上期总额）、`CHK-G-COVERAGE`（分析行数≤原始行数）、`CHK-G-AMOUNT`、`CHK-G-RECON`（对账差额≤0.02）、`CHK-G-NA`。

## 文字纪律

`CHK-TXT-*`：模块解读必须同时含 `【问题】【假设】【动作】`，否则 FAIL。
