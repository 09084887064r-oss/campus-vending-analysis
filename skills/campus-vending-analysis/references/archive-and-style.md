# 归档、环比与样式

## 周期键

- 周报：ISO 周 `2026-W45`（周一~周日）。上月/上周键由程序计算，不手填。
- 月报：自然月 `2026-11`。周报与月报目录互不覆盖。

## 数据根目录（谁决定、怎么固定）

preflight 的 `Q0_archive_root` 是阻断性问题：给默认值（`文档/售货机数据归档`）或用户自定义绝对路径，确认后写进 `config.archive_root`。此后每期沿用该根目录；`--data-root` 只做临时覆盖。
换根目录等于换一套历史，环比会断档——所以这件事只在第一次问，且写进配置留痕。

## 环比

`变化额 = 本期 − 上期`；`变化率 = 变化额 ÷ 上期`；上期为 0 → 变化率 `N/A`（不写 ∞、不写 100%）。

基准来源优先级：`processed/<上期键>/facts.csv`（归档）→ 缺失则 N/A。
口径指纹 = 价格带档位 + 单品规则版本 + 人数表 hash + 列映射 + 负数策略。
指纹不一致 → 上期仍可用但标 WARN，说明"口径变更不可比"（不静默照算）。

首期没有上期是正常状态：环比列全 N/A，报告写"无上期数据，未计算环比"。

## 归档纪律

```
<数据根>/raw/<键>/  processed/<键>/{facts.csv,meta.json}  reports/<键>/{xlsx,html,docx,uplift_points.csv}
```
同一期重复运行：退出码 7 停下等确认 → `--force` 后旧文件另存 `.bak`（已存在则 `.bak2`…）→ 写 `manifest.jsonl`。

## 样式套用

优先级 ① 用户明文规格（金额千分位两位小数 `#,##0.00`、占比 `0.00%`、环比红涨绿跌）
② 模板实测（表头底色/字体/边框/列宽/冻结/对齐）③ 内置默认。

- 模板只提供格式，不提供数据；
- 模板缺失/损坏 → 回退 `style.default_profile()`，并在「00_说明」写明原因，不中断报错；
- 环比红绿用 Excel 条件格式规则（`CellIsRule` greaterThan/lessThan），不是逐格染色。
