# 增长点规则库（R01–R09）

每条规则都必须产出：问题 + 数据证据（可指回表格）+ 影响范围 + 原因假设 + 动作 + 预期效果 + 验证方式 + 优先级。
证据为空、或原因没写"假设"，该条直接丢弃。

| ID | 触发条件 | 问题定性 | 动作方向 |
|---|---|---|---|
| R01 | 机组销售额环比 ≤ -3% 且 用户数环比 ≥ -1% | 转化下降（人来没买） | 查缺货/换品/陈列，补热品 |
| R02 | 机组销售额 ≤ -3% 且 用户数 ≤ -3% | 客流流失 | 楼栋拉新、查动线与分流 |
| R03 | 整体销售额涨 但 销售数量跌 | 量跌价升，增长质量差 | 便宜档补高动销，锁件单价上限 |
| R04 | 某价格带 单品数 +≥3 但销量跌 | 上架多动销低 | 尾部 SKU 汰换 |
| R05 | 某价格带 单品数没增 但销量 +≥10% | 需求未被满足 | 该档补 2–3 个 SKU |
| R06 | 某品类上期有量、本期归零 | 断货 or 主动汰换 | 先查断货再谈汰换 |
| R07 | 某品类 销售额与销量双跌 | 按金额减少额排序，写「在 N 个下滑品类中跌幅第 K 名」 | 恢复排面/补货/下架尾部 |
| R08 | 单小时：上期成交 ≥15 笔且销售额 ≤ -15% 但用户数 ≥ -2%；样本不足时按相邻 2–3 小时合并（≥30 笔、≤ -12%） | 有客流无销售 | 补货时点前移、时段选品 |
| R09 | 楼栋渗透率 < max(15%, 全校×0.7) | 渗透率低 | 楼栋入口首单券 + 低价档前置 |

## 优先级打分

`score = 金额影响×0.6 + 跌幅×100 + 其他项`。P0 ≥ 400，P1 ≥ 120，其余 P2。
清单最多 20 条，按分数降序，同模块同对象去重。
时点类（R08）最多 3 条，且必须过样本闸门：单小时上期成交 ≥ `MIN_HOUR_DEALS`（15 笔）、金额影响 ≥ max(60 元, 总额 0.5%)；不足则合并窗口（≥30 笔、影响 ≥ 总额 0.8%），文字里写明"单小时样本不足，按窗口合并"。表格仍保留 24 行全量。

## 文字模板

```
【问题】<哪个对象> ＜指标＞ 环比 X%（对比对象：上期/其他分组）
【假设】原因假设：<最可能原因>（可能是 A，也可能是 B，需现场核查）
【动作】<具体动作含数量与时点>；预期：<可量化>；验证：<看哪个指标、下期比什么、门槛>
```
